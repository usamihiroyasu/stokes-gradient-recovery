# Temporal Stokes fitting of a rocking dielectric interface

This fixed simulation generates four ideal analyzer observations of a single air/dielectric reflection while the incidence angle changes through Brewster's angle. It uses the exact Fresnel coefficients for refractive index 1.5, independent Poisson shot noise and Gaussian read noise. The polarization state is generated by the physical model, and the original folded-head arms start from the same fixed raw coordinate, independently of the truth.

The registered grid has 24 sequences of 41 frames: two orientation trajectories, three constant unpolarized background levels, two photon scales and two seeds. Every arm observes the same 984 frames but carries its own fitted state. These are dependent temporal observations within a fixed physical model. They do not estimate prevalence in real cameras. The objective is unweighted quadratic least squares, rather than Poisson maximum likelihood.

The physics follows [the dielectric Fresnel equations in PBRT](https://pbr-book.org/3ed-2018/Reflection_Models/Specular_Reflection_and_Transmission). The precise geometry, acquisition model, seeds, solver options, thresholds and stopping rule were saved in `PROTOCOL.json` before optimization. No grid expansion was performed after inspecting results.

## Fixed-grid results

A false success is native solver acceptance with objective gap greater than 1e-6 to the direct physical cone optimum. Every row below uses all 984 frames.

| Solver | Raw folded warm start | Curvature audit and restart | Physical-gradient audit and restart |
| --- | ---: | ---: | ---: |
| BFGS | 9 | 0 | 0 |
| L-BFGS-B | 7 | 0 | 0 |

All arms have zero native solver failures in this grid. Each audit controller restarts seven times per solver; its corrections propagate to later frames, so its intervention count need not equal the raw branch's bad-frame count. On the uncorrected endpoints, the local curvature test detects all nine and seven false successes, without flagging an accurate accepted endpoint. The physical bound also rejects all those false successes. This supports a physically specified example of the termination mechanism and its diagnosis. It establishes no accuracy or cost advantage of the curvature test over the available physical gradient or direct cone solution.

Direct-cone truth Stokes RMSE is 0.0251904; BFGS raw and audited RMSE are 0.0252375 and 0.0251904. Noise dominates the mean error. Errors occur with background levels zero and 0.02; none occur at 0.1 in this grid. Both fixed and rocking orientation cases contribute. Counts and subgroup records are retained in `results.json`.

The original monotone-map BFGS control uses the same raw starting coordinate, which produces a different physical initial state. A separately recorded correction audit in `MATCHED_CONTROL_PROTOCOL.json` matches the initial physical state exactly and reuses all the same observations and options. Both controls have 160 false successes under the same absolute head-gradient tolerance; both records are retained. No physical conditions or seeds were added. That map approaches the cone boundary only at infinite raw radius and has different conditioning; this fixed-tolerance result is not a general ranking of parametrizations.

## Verification and costs

`preflight.json` checks 20 cone minima using an independent physical-coordinate SLSQP solve, with maximum objective discrepancy below 2e-14. The new monotone-map gradient has central-difference discrepancy below 1.1e-10. `independent_AD_audit.json` uses PyTorch float64 differentiation at all 16 raw false successes and the 48 initial sequence endpoints; the maximum radial-curvature discrepancy is below 7e-16.

The recorded Hessian queries distinguish coverage logging from a deployable radius guard. For each raw folded arm, the script evaluates 984 initial endpoint Hessians for coverage. The curvature controller requires 22 initial guarded Hessians per solver. Physical auditing requires zero Hessians; its 22 initial Hessians in this script are extra diagnostic logging. The saved records also include final-endpoint diagnostics: these repeat a Hessian for a final near-fold endpoint and are additional verification overhead, not controller requirements. Optimizer timing excludes the diagnostics, trial calls, and reference cone evaluation, and is not used to claim a runtime advantage. Trial, optimizer and diagnostic evaluations are different costs.

## Reproduction

The ZIP preserves the directory structure and includes `verification/verify_warm_start.py`, the existing verified head-coordinate numerical core. Python 3.12.3, NumPy 2.5.4, SciPy 1.18.1 and Matplotlib 3.11.2 were used locally. Optional independent AD checks used Python 3.11.6 and PyTorch 2.9.1.

From the extracted root, install `application/fresnel_sequence/requirements.txt` in a virtual environment, then run:

```sh
python application/fresnel_sequence/reproduce.py --output /tmp/stokes-fresnel-replay
python application/fresnel_sequence/figure.py
```

Select a new or empty replay directory. The wrapper preserves these reference outputs and compares observation hashes and scientific summaries, excluding timing; it also replays the correction control with the matched initial physical state. The raw `run.py` refuses to overwrite its registered protocol. `audit_ad.py` requires the optional PyTorch environment.

`fresnel_pilot.png` and `.svg` show the complete-grid counts and one example selected by the largest BFGS baseline objective gap. The simulation is reported in Section VII-D and Supplement S18 of the manuscript.
