This package has not been submitted. It is not a submission-complete package.
Venue-specific declarations and the data-availability statement require
author review before submission.

Build with Python 3 and a current TeX Live installation: python3 build.py
Packages include geometry, natbib, wrapfig, sttools, threeparttable, appendix,
xcolor, float, amsmath, amssymb, amsthm, mathtools, booktabs, tabularx, microtype,
placeins, etoolbox, xurl, hyperref, and xr-hyper. Do not enable shell escape.
The two PDFs use mutual external references; keep them in the same folder.

The unmodified sn-jnl.cls is from the official Springer Nature LaTeX template,
version 3.1, December 2024. Its copyright and licence notice are retained.
Template source: https://www.springernature.com/gp/authors/campaigns/latex-author-support

Scientific equations, proof environments, figures and tables are retained from
the preceding author version; five tables have moved to Supplementary Section S22.
